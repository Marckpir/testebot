Consulta APR por NS

Bem-vindo ao sistema de consulta APR por NS. Esta interface está disponível para visualização estática no GitHub Pages.
Para utilizar todas as funcionalidades (consulta, exportação, anexos), execute o servidor Node.js localmente.

Como usar

  1. Clone o repositório: git clone ...
  2. Instale as dependências: npm install
  3. Execute o servidor: npm start ou node server.js
  4. Acesse http://localhost:3000 no navegador.
